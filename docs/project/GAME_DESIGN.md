# GAME_DESIGN — The Pawntom Heist

> 노션 기획서 + 피그마 기획 보드(v2)를 요약한 문서입니다. 원문 대신 이 문서를 읽고 작업합니다.
> 수치·규칙은 요약이므로, 밸런싱 확정 작업 시에는 원문 확인이 필요할 수 있습니다.

### 핵심 특징 4가지

1. **털공(흔적) 기반 추적** — 적 AI는 시각이 아닌 후각으로 추적. 격하게 움직일수록(달리기·점프) 바닥에 털공이 남고, AI는 흔적의 신선도를 계산해 뒤를 쫓음.
2. **시점 통일 + 유동적 역할 전환** — 오퍼레이터/침투조를 시스템적으로 분리하지 않음. 모두 동일한 1인칭이며, 본부 터미널을 잡으면 오퍼레이터, 놓고 나가면 침투조.
3. **야간 투시와 암전 플레이** — 전 캐릭터 공통 패시브. 본부가 구역 전력을 끊어 적 시야를 줄이고, 침투조는 암전 구역을 통과.
4. **하이리스크 본부 서포트** — 스프링클러는 광역 흔적 제거 수단이지만, 가동 소음이 적을 유인하고 아군에게 감속 디버프를 줌.

## 2. 코어 루프

게임은 **4일간의 캠페인(Stage 1~4)** 이며, 매 스테이지가 아래 흐름을 반복합니다.

```
[1. 준비: 암시장]      가젯 구입 및 인벤토리 세팅
        ▲
        │ (재화 획득)
[5. 보상: 환전]        전리품 가치 정산 + 전원 생존 보너스 x1.2
        ▲
        │ (무사 귀환)
[4. 도주: 캣닢 확보]   경보 발동 → 브루투스 스폰 → 격벽 원격 조작하며 탈출구로
        ▲
        │ (목표 달성)
[3. 수집: 위험 감수]   K-9·브루투스 회피, 흔적 지우기, 서브 전리품 루팅
        ▲
        │ (구역 진입)
[2. 침투: 역할 분담]   현장조(보안 노드 링크) ↔ 오퍼레이터(CCTV·격벽 원격 개방)
```

| 페이즈 | 내용 |
|---|---|
| 1. 작전 준비 | 은신처의 2D 콘솔 상점에서 재화로 가젯 구매. 인벤토리는 핫바 4칸 고정 |
| 2. 잠입·파밍 | 현장조는 서브 전리품 루팅 + 보안 노드(분전반) 접촉·캐스팅, 본부는 해킹 미니게임으로 CCTV 지도 해금 후 지시 |
| 3. 발동·도주 | 전설의 캣닢 획득 즉시 경보(맵 전체 붉게 점멸) → 브루투스 스폰 → 전면 추격전, 본부 귀환 목표 |
| 4. 정산·결과 | 캣닢 소지 상태로 탈출 수단 가동 시 성공. 전리품 환전, 전원 생존 시 x1.2 |

- 단계가 오를수록 접근 가능 층이 누적(1→4층)되고, 캣닢 금고는 각 단계 최상층에 고정 배치.
- 진입 지점은 모든 단계에서 1층으로 동일. 본부도 1층 고정 → 단계가 오를수록 무전 의존도 상승.
- 죽은 인원의 아이템은 현장에 유실물로 남음.

## 3. 주요 시스템

### 3.1 플레이어

- **시점**: 1인칭 FPS (카메라 배치는 PEAK 방식 채택)
- **공통 패시브 — 야간 투시**: 조명이 꺼진 구역 진입 시 자동 활성화. 시각 연출 미확정
- **매달리기**: 공통 이동 액션이나 현재 구현 보류
- **1인칭 HUD 배치**: 좌상단 HP·스태미나 바 / 우상단 미니맵 / 하단 중앙 핫바 4칸 / 우하단 무전기 / 타 플레이어 조준 시 머리 위 이름표 + HP 바

**스태미나 (최대 100)**

| 상태 | 입력 | 효과 |
|---|---|---|
| Idle / Walk | — | 초당 +20 회복 |
| Sprint | Shift | 이동 속도 x1.5, 초당 -10 |
| Jump | Space | 1회 -15 |
| Parkour | 벽면 접촉 체공 | 초당 -35 |
| Exhausted | 스태미나 0 도달 | 3초간 Sprint·Jump 입력 무시, 강제 Walk |

**털공 흔적** — *이동 거리* 기반(시간 기반 아님). 직전 털공 좌표에서 일정 거리 이상 이동하면 바닥으로 레이캐스트를 쏴 털공 프리팹 생성. 각 털공은 생성 시점을 함께 저장해 신선도 판별에 사용. 달릴 때는 보폭이 커져 흔적이 넓고 빠르게 퍼짐. (시간 단위 생성은 정지 상태에서도 흔적이 쌓여 은신 플레이가 무너지므로 배제)

**무게** — 핫바 4칸 아이템 무게의 합. 페널티는 **이동 속도 감소 하나로 한정**(흔적 생성량·스태미나 소모에는 관여하지 않음). 전리품·가젯·열쇠가 같은 4칸을 공유하므로 "많이 챙기면 대응 수단을 버려야 하는" 선택 구도. *구간별 감속 수치 미확정.*

### 3.2 캐릭터 4종

설계 원칙: **이동 경로 접근 권한을 특정 캐릭터가 독점하지 않는다.** 차별화는 접근 권한이 아니라 효율 차이로 부여.

| 캐릭터 | 역할 / 스탯 | 능력 |
|---|---|---|
| 깜냥이 (BlackCat) | 에이전트 / 스피드 | 이동 속도·기본 스태미나 증가, 파쿠르 스태미나 소모 감소 |
| 치즈냥이 (OrangeCat) | 브루저 / 힘 | 경직 디버프 무시. 액티브: Locked 일반 문 앞 F 길게 → 강제 개방(캐스팅) |
| 고등어냥이 (TabbyCat) | 오퍼레이터 / 지능 | 미니게임 제한 시간 +30%, 오타 패널티 1회 무효, 평면도 적 NPC 마커에 상태 표시 |
| 카오스 삼색 (CalicoCat) | 스카우트 / 은신 | 털공 생성 쿨타임 2배, 소형 환풍구 등 특수 통로 통과 |

- 고등어냥이는 터미널 4탭 조작 자체가 능동 행동이라 별도 액티브 없음.
- 치즈냥이 강제 개방은 **일반 문 한정(최종 금고 불가)**, 캐스팅 중 이동 불가·스태미나 대량 소모·완료 시 소음 이벤트. 본부 해킹(조용하지만 원격 조작 필요)과의 비대칭 선택지.
- 로비 캐릭터 선택 UI의 스탯 표기는 지능/힘/은신/스피드 4축 다이아몬드.

### 3.3 적 AI

**흔적 추적 공통 로직** — 일정 주기로 반경 내 털공 스캔 → 가장 최근 생성된 털공을 목표 좌표로 설정 → 도달 후 재스캔하며 동선을 점진 추적.

**K-9 (일반 순찰견) 상태 머신**

| 상태 | 전환 조건 | 행동 |
|---|---|---|
| Patrol | 기본 | 지정 경로 또는 무작위 이동, 느림 |
| Investigate | 스캔 반경 내 털공 감지 | 흔적 추적, 접촉한 털공 파괴 후 다음 탐색. 20초간 신규 털공 미발견 시 Patrol 복귀 |
| Alert | 플레이어와 충돌 또는 초근접 | 제자리 하울링. 반경 30m 내 K-9을 Investigate로 강제 전환 + 하울링 좌표로 소집 |
| Chase | Alert 이후 시야 내 존재 | 플레이어 좌표 직접 추격, 속도 증가. 5초 이상 시야 소실 시 Investigate 복귀 |

**브루투스 (네임드 NPC)**

| 상태 | 전환 조건 | 행동 |
|---|---|---|
| Patrol | 기본 | K-9보다 넓은 반경을 빠르게 순찰. K-9 하울링을 들으면 즉시 그 좌표로 이동 |
| Enraged | 털공 감지 | 최신 털공 경로로 전력 질주, 코너에서 미끄러지는 묵직한 가속도 |
| Breach | 경로 상 닫힌 문 존재 | 전방 짧은 레이캐스트로 문 감지 → 3초간 3회 충돌 → 문 파괴 후 추격 재개 |

- 브루투스는 문을 우회하지 않고 문을 포함한 최단 경로를 계산. 충돌 판정마다 문 내구도 차감.
- 파괴된 문·격벽은 본부 격벽 뷰에서 **통제 불가(Error)** 로 표기되어 조작 불가.
- 아트 방향: K-9은 저먼 셰퍼드/말리노이즈 계열(4~5등신, 흐릿한 눈·강조된 코, 전술 조끼, 암전 시인성용 야광 요소), 브루투스는 케인 코르소/로트와일러 계열(3~4등신, 두꺼운 목·어깨, 흉터, 추적 시 붉은 안광).

### 3.4 본부 터미널

**진입/이탈** — 모니터 앞 콜라이더에서 F. 진입 시 이동(WASD)·시점 비활성화 + 메인 카메라에 터미널 팝업. 다시 F로 플레이어 시점 복귀.

**공통 규칙 (탭 4종 = 격벽 조작 / CCTV / 스프링클러 / 전등)**

- 4탭 모두 **동일한 2D 평면도**를 쓰고 표시·조작 대상만 달라짐. 뷰별로 따로 만들면 작업량이 4배 → 공용 평면도 컴포넌트 → 탭 → 각 뷰 로직 순서로 구현.
- 평면도는 **층·단계별 레벨 데이터를 읽어 그린다. 씬 하드코딩 금지.**
- 층 셀렉터 필요(본부는 1층 고정, 침투조는 4층까지 이동). *입력 방식 미확정.*
- **뷰 상태 공유**: 한 탭에서 이동/확대하면 나머지 3탭에도 동일 좌표·배율 적용.
- 확대·축소 = 마우스 휠, 이동 = 마우스 드래그.
- 모든 본부 조작 뷰는 **팝업 형태**로 가정.
- 작업 큐(동시 조작 수 3칸 제한) — 본부 전체 4작업을 포함 대상으로 논의 중이나 **도입 여부 미확정.**

**CCTV 뷰** — 실시간 영상 피드가 아니라 평면도 위에 아군/적 NPC 위치 + 미해금 구역 마스킹을 표시.

| 단계 | 상태 | 연출 |
|---|---|---|
| 초기 | 본부 도킹 구역만 해금, 그 외 잠금 | 미해금 구역 마스킹 + "NO SIGNAL" 출력 |
| 링크 트리거 | 침투조가 분전반(보안 노드) 검색 후 F | 3초 캐스팅, 이동 불가 |
| 최종 해금 | 구역 해금 전체 동기화 | 마스킹 해제, 구조·아군·적 마커 표시 |

- 도킹 구역 1곳을 초기 해금해 게임 시작 직후의 정보 공백 제거.
- 오퍼레이터(고등어냥이) 조작 시에만 적 마커에 상태 아이콘(Patrol/Investigate/Alert/Chase) 부착. 그 외 캐릭터는 위치 마커만. 정보만 늘고 조작 권한은 그대로라 협동 요구가 증가.
- 팀원이 공간에 진입해도 해당 구역이 해금됨(피그마 CCTV 뷰 주석).

**격벽 상태 머신**

| 상태 | 전환 조건 | 피드백 | 물리 규칙 |
|---|---|---|---|
| Locked | 기본 | 빨간 LED, 평면도 붉은색, 상호작용 시 "접근 거부" | 침투조 F로 개방 불가. 해킹 또는 치즈냥이 강제 개방만 가능 |
| Unlocked | 미니게임 성공 | 초록 LED, 평면도 푸른색 | 침투조 F로 Open. 본부가 푸른 격벽 더블클릭 시 즉시 폐쇄 |
| Open | Unlocked에서 F 상호작용 | 개방 애니메이션·구동음 | 통행 가능, 5초 후 자동 Unlocked 회귀 |
| Destroyed | 브루투스에 의해 내구도 소진 | 문이 찌그러져 바닥에 방치, 평면도 푸른색 고정 + X 아이콘 | 영구 개방 고정, 본부 제어권 완전 상실 |

- **접촉 링크**: 격벽 앞 근접 트리거에 침투조가 들어오면 **입력 없이 자동 연동**. 별도 입력을 요구하면 순수한 조작 부담만 생기므로 자동 판정. 대신 LED 점멸 + 링크음 피드백이 필수(없으면 기여 사실을 인지하지 못함). 링크 상태는 스테이지 종료까지 유지. 스프링클러 표시 조건과 동일 판정이라 **접촉 트리거 컴포넌트를 공용 사용**.
- 격벽 공격 판정은 배제(내구도가 없는 대상을 때릴 수 있으면 파괴 가능하다는 오해 유발).
- **붉은 격벽 더블클릭 판정 순서**: ① 구역이 해금 상태면 즉시 개방 ② 미해금 + 침투조 접촉 완료면 미니게임 팝업 ③ 둘 다 아니면 접근 불가 팝업.
- 실패 시: 세션 강제 종료, 노드 3초 쿨타임, 현장 키패드 경보음(소음 이벤트 → 주변 적 어그로 유인).

**스프링클러**

| 단계 | 흐름 | 반응 |
|---|---|---|
| 표시 조건 | 구역 해금 + 침투조 접촉 완료 | 두 조건 충족 전까지 평면도에 아이콘 미표시 |
| 필드 가동 | 아이콘 클릭 → 미니게임 클리어 시 즉시 작동 | 천장 파티클, 평면도에 5초간 작동 구역 표시 |
| 흔적 정화 | 필드 내 흔적 스캔 | 영역 내 털공 전부 즉시 파괴 |
| 플레이어 디버프 | 필드 내 플레이어 실시간 스캔 | 이동 속도 감소, 구역 이탈 후 3초간 유지 |
| 어그로 전이 | 가동 즉시 필드 중심으로 소음 이벤트 발행 | 주변 적 목표 좌표 갱신 + Investigate 전환 |
| 재사용 제한 | 작동 후 사용 완료 전환 | 평면도에서 회색 처리, 스테이지 종료까지 재사용 불가 |

배치는 방 구조 천장 중앙. 캣닢 소지자가 쓸 수 있는 유일한 광역 흔적 제거 수단이라 필수 유지.

**전등** — 전등 탭에서 구역 버튼 클릭 → 미니게임 팝업 → 성공 시 구역 소등(침투조 야간 투시 자동 활성화, 적 NPC 시야 판정 거리 감소) → **5초 후 자동 점등**. EMP 폭탄이 같은 소등 처리를 현장에서 재사용.

**변수(돌발 상황) 시스템** — 사전 배치 트리거 발동 → 터미널 전체를 덮는 경고 팝업("⚠️ 경고! 본부를 조작할 수 없습니다.") → 평면도 갱신 중단 + 4개 탭 버튼 적색·비활성 → 해제 조건 충족 후 X 클릭으로 복구. *3종 미확정.* 후보: 컴퓨터 발화(소화기로 진화) / 본부 기울어짐(파쿠르 이동 후 정상화 버튼) / 본부에 적 NPC 진입(은신 대기).

### 3.5 해킹 미니게임 3종

호출 주체가 격벽·스프링클러·전등 3종이므로 **공통 인터페이스**로 호출(노드 종류 + 보안 등급 전달, 성공·실패 콜백). 팝업 중 이동(WASD) 입력 차단(입력 가로채기), Esc로 세션 취소. 성공 시 호출 노드의 콜백 실행 후 전체 동기화, 실패 시 팝업 종료 + 3초 쿨타임 + 경보음. 보안 등급(일반 문 / 최종 금고)에 따라 3종 중 하나가 무작위 생성.

| 미니게임 | 판정 로직 | 클리어 / 패배 |
|---|---|---|
| 커맨드 오버라이드 (시퀀스 입력형) | 지정 순서(일반 문 4단계, 금고 8단계)와 일치 판정. 불일치 시 처음부터 + 에러음 | 제한 시간 내 완주 / 5초 초과 |
| 디지털 게이지 싱크 (타이밍 압박형) | 좌우 왕복 표시자가 적중 구간을 지날 때 Space | 연속 2~3회 적중 / 10초 초과. 구간 밖 입력 시 연속 횟수 초기화 + 적중 구간 폭 10% 축소 |
| 시그널 디바이드 (고속 연타형) | 두 키(A·D) 교차 입력. 직전과 다른 키일 때만 진행도 증가(동일 키 연속은 무시) | 진행도 100% 도달 / 5초 초과. 자연 감소 초당 5%p |

### 3.6 아이템 · 인벤토리

**슬롯 구조** — 핫바 4칸(1~4)에 전리품·가젯·열쇠가 **함께** 들어감. 전리품은 크기 구분 없이 1칸씩 점유. 선택 상태는 인덱스 1개(0~3)이며 별도 칸으로 그리지 않고 하이라이트만. 가젯은 선택 상태일 때만 사용 가능.

| 입력 | 동작 |
|---|---|
| 1~4 | 해당 슬롯 즉시 선택, 다시 누르면 선택 해제. 슬롯 간 아이템 이동 조작은 없음 |
| 마우스 휠 | 인접 슬롯으로 선택 순환 |
| — | 선택 변경 시 0.3~0.5초 교체 시간, 교체 중 가젯 사용 불가 |
| F | 루팅 — 빈 슬롯 탐색 + 아이템 정보 바인딩 + 총 무게 갱신. 빈 슬롯 없으면 "가방 가득 참" 경고 |
| 우클릭 | 선택 슬롯 가젯 사용 (사용 방식별 분기), 수량 소진 시 슬롯 비움 |
| Q | 수동 드롭 — 슬롯 비우고 월드 오브젝트 생성, 전방 한 칸 앞으로 배출(마인크래프트 방식) |
| E | 아이템 상세 팝업(설명·금액·무게). X 버튼 또는 Esc로 닫기 |

탈출 정산 시 인벤토리를 스캔해 전리품 가치를 합산 후 팀 재화에 가산하고 인벤토리에서 제거.

**가젯 사용 방식별 우클릭 분기** — 입력 체계를 키보드(이동·월드 상호작용 F) / 마우스(전투 좌클릭·아이템 사용 우클릭)로 분리. 우클릭은 "이 슬롯 아이템을 쓴다"는 단일 의미만 가지고, 이후 동작은 아이템의 *사용 방식* 속성이 결정.

| 사용 방식 | 입력 패턴 | 사용 중 이동 | 예시 |
|---|---|---|---|
| 캐스팅형 (자기 효과) | 길게 눌러 로딩바(시계방향 원형 게이지)를 채움 → 완료 시 발동 | 불가 | 돌돌이, 응급 츄르 |
| 지속형 (자기 버프) | 짧게 눌러 즉시 발동 | 가능 | 탈취 스프레이, 개다래 가루 |
| 투척형 | 누르고 있는 동안 조준 궤적 표시, 떼는 순간 투척 | 가능 | EMP 폭탄, 삑삑이 장난감 |
| 거치형 | 짧게 눌러 정면 고정 거리에 배치 | 가능 | 마취 츄르 |

**가젯 4종 (암시장)**

| 아이템 | 가격 | 소지 제한 | 지속/캐스팅 | 효과 |
|---|---|---|---|---|
| 돌돌이 | $100 | 슬롯당 1 | 캐스팅 1초 | 발밑 반경 2m 스캔, 반경 내 털공 일괄 파괴. 작동 중 이동 속도 0 |
| 탈취 스프레이 | $250 | 슬롯당 1 | 지속 15초 | 달리기·점프에도 털공 미생성 |
| EMP 폭탄 | $400 | 슬롯당 1 | 지속 5초 | 투척형. 낙하 지점 반경 조명 강제 차단 → 야간 투시 활성 + 적 시야 거리 감소 |
| 마취 츄르 | $300 | 슬롯당 1 | 지속 8초 | 지면 거치 유인형. 순찰견이 최우선 접근 후 8초 스턴 (브루투스 면역) |

- 전등(본부)과 EMP의 역할 분담: 본부 전등은 비용 없이 반복 가능하나 구역 해금 + 미니게임 필요, EMP는 해금 여부 무관 즉시 발동하나 구매 필요 + 슬롯 1칸 차지.
- *가젯 4종 무게 미확정* — 전리품보다 낮게 잡아야 "전리품을 포기하고 대응 수단을 챙기는" 선택이 성립.

**전리품** — 뼈, 도자기, 원석, 그림 작품, 전설의 캣닢. 가치와 무게를 독립 설정(비싸고 무거운 것 ↔ 싸고 가벼운 것). *수치 미확정.*

### 3.7 사망 · 게임 종료

**사망 4단계**: 적 AI 충돌로 HP 0 이하 → 조작 컨트롤러 비활성화 + 쓰러짐 애니메이션·화면 흑백 → 아이템 드롭(전리품·가젯·열쇠 데이터를 사망 좌표에 프리팹 생성) → 흔적 각인(이펙트 + 평면도에서 해당 팀원 점 소멸) → 관전 전환(부활 불가, 생존 팀원 1인칭 관전).

**전설의 캣닢 소지 디버프** — 목표 달성 직후 구간의 난이도를 최고점으로 끌어올리는 장치.

| 디버프 | 규칙 | 설계 의도 |
|---|---|---|
| 마킹 (레드 도트) | 이동하지 않아도 일정 주기로 털공 생성 | 기존 흔적 알고리즘 재사용(K-9 상태 머신 수정 불필요). 동행 팀원까지 위험해져 뭉치기 전략 무력화 |
| 이동 속도 감소 | 캣닢 무게를 매우 높게 설정 | 무게 시스템 재사용, 별도 구현 불필요 |
| 무전 차단 | 소지자 발신·수신 차단 | 본부 정보 단절. 근접 음성으로 대체하려면 팀원이 접근해야 하고, 접근하면 마킹에 함께 노출 |

- 해제 수단은 돌돌이 / 탈취 스프레이 / 스프링클러. 슬롯·재화·시간을 소모하므로 회피 불가능한 벽이 아니라 자원 압박으로 작동.
- 캣닢은 팀원 간 인계 가능(디버프도 함께 이전 → 릴레이 전술).
- 소지자 사망 시 캣닢도 함께 드롭되고 디버프는 새 획득자에게 이전.

**종료 판정**

| 결과 | 트리거 | 처리 |
|---|---|---|
| 탈출 성공 | 캣닢 소지자 1명 이상이 탈출구 진입 + 탈출 수단 가동 | 생존 전리품 일괄 환전, 전원 생존 시 x1.2 → 상점 이동, 다음 층 해금 및 보안 레벨 상승 |
| 작전 실패 | 전원 사망, 또는 캣닢 회수 없이 탈출구로 도주 | 서브 루팅·캣닢 데이터 파괴, 사망 전 정산 완료분도 파괴, 스테이지 초기화 후 1단계 회귀 → 게임 오버 결과창 후 로비 |

### 3.8 스테이지 · 맵 구조

| 단계 | 접근 가능 층 | 캣닢 금고 위치 | 필요 열쇠 |
|---|---|---|---|
| 1단계 | 1층 | 1층 고정 | 1개 |
| 2단계 | 1~2층 | 2층 고정 | 2개 |
| 3단계 | 1~3층 | 3층 고정 | 3개 |
| 4단계 | 1~4층 | 4층 고정 | 4개 |

- 단계가 오를 때마다 격벽 배치, 아이템 배치, 적 NPC 순찰 동선이 변경되어 차별화.
- **열쇠**: 인벤토리 슬롯을 점유하는 일반 아이템(전리품·가젯과 4칸 공유). 접근 가능 층 전역에 무작위 배치, 사망 시 사망 좌표에 드롭. N단계는 열쇠 N개가 필요하므로 4단계에서는 열쇠가 인벤토리 전체를 점유할 수 있어 분담 협업이 유도됨.
- **금고 개방(부분 개방 방식)**: 열쇠 소지 상태로 금고에 F → 대응하는 잠금 1개 해제 + 해당 열쇠 소모 → 모든 잠금 해제 시 미니게임 가능 상태 → 성공 시 최종 개방. 열쇠 단위로 풀리므로 여러 명이 순서 무관하게 기여 가능하고, 마지막 미니게임이 완결 지점이 됨.
- **본부 도킹**: 1층에 도킹 지점 3곳 사전 배치, 스테이지 시작 시 1곳 무작위 선택. 본부는 스테이지당 1개이며 전원 동일 본부에서 스폰. 나머지 2곳은 막다른 벽으로 폐쇄. *탈출구 활용 여부 미확정.*
- **레벨 데이터로 분리해야 하는 항목**(씬 하드코딩 금지): 격벽(좌표·보안 등급) / 아이템(전리품 좌표·가치·무게) / 적 NPC(K-9 순찰 경로, 브루투스 광역 순찰 반경) / 금고(좌표·보안 등급) / 열쇠(단계별 개수, 배치 후보 지점 풀) / 환경 제어(스프링클러 좌표, 전등 구역 분할) / 변수(종류·발동 지점) / 평면도(층별 구조도).
- 맵 기본 구조: 본부 + 스폰 장소 + 통로(박물관 연결) + 변수 지점 3곳 + 탈출 버튼. 1층·2층 초안 작성됨(1층은 문+환풍구·이동 동선·적 순찰 루트(미정), 2층은 문+열쇠·이동 동선 표기).

### 3.9 음성 통신

- **근접 음성**: 반경 내 자동 전달, 거리 감쇠. 본부(1층)와 침투조(최대 4층)는 근접 음성만으로 대화 불가.
- **무전기**: HUD 우하단 상시 표시. T로 발신(눌러서 말하기, 자신 제외 전원에게 송신), M으로 비활성화(발신·수신 모두 차단 — 적이 근처일 때 사용). 층·거리 무관 팀 전체 전달. 캣닢 소지 중에는 차단.
- 아이콘 상태: 발신 인식 중 초록으로 차오름 / 수신 중 온전한 초록 / 비활성 빨강 + 취소선.
- 로비 마이크 아이콘 3상태: 말하는 중 초록 / 평시 회색 / 차단 빨강. 플레이어 이름은 각자의 스팀 아이디.

### 3.10 입력 키 정리

**침투조(현장)** — WASD 이동 / Shift 달리기 / Space 점프 / 마우스 시점 회전 / **F 컨텍스트 상호작용**(루팅·보안 노드 캐스팅·격벽 개방·금고 개방·터미널 진입 이탈) / F 길게 = 치즈냥이 강제 개방 / 1~4 핫바 선택 / 휠 슬롯 순환 / 좌클릭 근접 공격(대상: 적 NPC) / 우클릭 가젯 사용 / Q 드롭 / E 아이템 상세.

**본부(터미널)** — F 진입·이탈 / 탭 클릭 또는 TAB 뷰 전환 / 마우스 드래그 pan / 휠 확대·축소 / 더블클릭 격벽 조작 / 아이콘 클릭 스프링클러·전등 가동 / X 클릭 변수 경고 팝업 해제.

**미니게임** — 방향키(커맨드 오버라이드) / Space(디지털 게이지 싱크) / A·D(시그널 디바이드) / Esc 취소.

**공통** — T 무전 발신(눌러서 말하기), 근접 음성은 별도 입력 없이 자동.
