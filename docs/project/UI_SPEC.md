# UI_SPEC — The Pawntom Heist

> 피그마 기획 보드(FigJam) 「[TPH] 기획서 v2」의 화면 구성을 요약한 문서입니다.
>
> **중요**: 원본은 디자인 파일(`/design/`)이 아니라 **FigJam 화이트보드(`/board/`)** 입니다. 따라서
> Figma Variables·Styles·컴포넌트가 존재하지 않고, 색/폰트/간격은 **주석과 도형 라벨로만** 기술돼 있습니다.
> 아래 "디자인 토큰"은 확정된 값이 아니라 **기획 주석에서 추출한 시맨틱 규칙과 명시된 스프라이트 크기**이며,
> 2D 아트(장예주) 확정 시안이 나오면 갱신해야 합니다. HEX 값은 아직 어디에도 정의돼 있지 않습니다.

- 마이크 아이콘 3상태: 말하는 중 초록 / 평시 회색 / 꺼둠 빨간 차단 아이콘.

```
HQTerminalPopup                   # 모든 본부 조작 뷰는 팝업 형태
├─ TabBar                         # 순서 고정: 격벽조작 / CCTV / 스프링클러 / 전등

└─ FloorPlanView                  # 4탭이 공유하는 단일 2D 평면도 컴포넌트
```

**공유 규칙**: 한 탭에서 pan·zoom 하면 나머지 3탭도 동일 좌표·배율. 확대·축소는 휠, 이동은 드래그. 평면도는 레벨 데이터로부터 렌더링(씬 하드코딩 금지).

**탭별 노드 표현**

| 탭 | 노드 표시 | 조작 |
|---|---|---|
| 격벽조작 | 붉은 격벽 = 닫힘 / 푸른 격벽 = 열림 / 푸른색 고정 + X = 브루투스에 파괴됨(조작 불가) | 더블클릭 |
| CCTV | 아군 위치, 적 NPC 위치, 미해금 지역 | 표시 전용 |
| 스프링클러 | 해금 + 침투조 접촉 후에만 아이콘 표시. 작동 중 5초간 구역에 반투명 색상 박스. 사용 완료 시 회색 | 아이콘 클릭 |
| 전등 | 구역별 전등 버튼. 소등 구역은 어둡게 표시, 5초 뒤 자동 점등 | 버튼 클릭 |

**변수 발생 시**

```
HQWarningOverlay                  # 터미널 창 전체를 덮음
├─ WarningPanel "⚠️ 경고! 본부를 조작할 수 없습니다."
└─ CloseButton "X"                # 해제 조건 충족 후 X로 직접 닫아야 함
# 동시에: 평면도 갱신 중단, 탭 버튼 4개 적색 + 비활성
```

## 3. 디자인 토큰

### 3.1 크기 (피그마에 명시된 스프라이트 사이즈, px)

기획 보드에 "UI 스프라이트별 사이즈 표시해두었습니다"라고 명시된 값들입니다.

| 화면 | 요소 | 크기 |
|---|---|---|
| 캐릭터 선택 팝업 | 팝업 전체 | 1800 x 950 |
| | 캐릭터 일러스트 / 3D 모델 | 450 x 820 |
| | 캐릭터 이름표 | 700 x 120 |
| | 캐릭터 설명(능력치·패시브·서사) | 700 x 600 |
| | 열람 인디케이터(동그라미·세모) | 160 x 160 |
| | Select / UnSelect 버튼 | 150 x 40 |
| 로비 | 플레이어 이름표 | 280 x 70 |
| | 마이크 아이콘 | 70 x 70 |
| | 캐릭터 초상화 슬롯(원형) | 330 x 330 |
| | ShowTime! / Ready 버튼 | 400 x 150 |

- 캐릭터 선택 팝업의 기준 해상도(1800 x 950)를 그대로 로비 화면 기준으로도 사용합니다.
- 위 매핑은 피그마 라벨의 좌표 위치를 기준으로 정리한 것으로, 아트 전달 시 원본 보드에서 한 번 확인하는 것이 안전합니다.
- 그 외 화면(HUD, 본부 터미널, 미니게임)의 픽셀 사이즈는 **아직 표기되지 않았습니다** (마일스톤의 "UI 기획서(화면별 구성, 크기)"가 진행 중 항목).

### 3.2 색 (시맨틱 규칙 — HEX 미정)

| 토큰 | 값(의미) | 사용처 |
|---|---|---|
| `state/locked` | 붉은색 | 격벽 Locked, 평면도 닫힌 격벽, 현장 LED |
| `state/unlocked` | 푸른색 | 격벽 Unlocked·Open, 평면도 열린 격벽 |
| `state/unlocked-led` | 초록색 | 현장 격벽 패널 LED (Unlocked) |
| `state/destroyed` | 푸른색 고정 + X 아이콘 | 브루투스에 파괴된 격벽, 조작 불가(Error) |
| `state/disabled` | 회색 | 사용 완료 스프링클러, 선택 완료된 Select 버튼 |
| `state/danger` | 적색 | 변수 발생 시 탭 버튼, 경고 팝업 |
| `accent/selected` | 빨간 테두리·윤곽선 | 선택된 핫바 슬롯, 선택된 캐릭터 이름표(+체크) |
| `accent/action` | 빨간색 | 활성화된 시작(ShowTime!) 버튼 |
| `voice/active` | 초록색 | 말하는 중 마이크, 무전 발신 충전·수신 상태 |
| `voice/idle` | 회색 | 평시 마이크 |
| `voice/blocked` | 빨간색 (+취소선) | 마이크 차단, 무전기 비활성(M) |
| `hp/100-70` | 초록색 | 타 플레이어 이름표 색 |
| `hp/69-40` | 연녹색 | 〃 |
| `hp/39-20` | 노란색 | 〃 |
| `hp/19-1` | 빨간색 | 〃 |
| `map/masked` | 마스킹(해칭) + "NO SIGNAL" | 미해금 지역 |
| `map/sprinkler-active` | 반투명 색상 박스(5초) | 스프링클러 작동 중 구역 |

야간 투시(소등 구역) 톤은 "녹색 노이즈 + 명도 상승" 방향으로 스터디 중이며 확정 전입니다.

### 3.3 타이포그래피

방침: **기본 통일 폰트 1종 + 포인트 폰트 1종**. 아직 확정되지 않았습니다.

| 픽셀체 | 도스이야기, Neo둥근모 |

| 기본체 | 나눔고딕, 바탕체, Pretendard |

현재 리포지토리에 임포트된 TMP 폰트 애셋 (`Assets/08_Fonts/`):

| 파일 | 용도(추정) |
|---|---|
| `NanumBarunpenR SDF` (+ `.ttf`) | 간격 좁은 고딕 후보 = 본문 |
| `ThinDungGeunMo SDF` (+ `.ttf`) | 픽셀/둥근모 후보 = 포인트·터미널 |

피그마 보드에는 "폰트 비교용" 섹션에 적용 테스트 이미지만 있고 폰트 크기·행간 값은 없습니다.

### 3.4 간격 · 레이아웃 규칙

명시된 수치는 없고, 배치 규칙만 정의돼 있습니다.

- **1인칭 HUD 4모서리 규칙**: 좌상단 = HP·스태미나(+직군 아이콘), 우상단 = 미니맵, 하단 중앙 = 핫바 4칸, 우하단 = 무전기.
- **핫바**: 4칸 균등 가로 배치. 선택 칸은 별도 슬롯을 그리지 않고 하이라이트만. 슬롯 위에 아이템 이름 라벨.
- **본부 터미널**: 상단 탭 바(4개, 균등 폭 · 순서 고정) + 좌상단 줌 라벨 + 우상단 X 버튼 + 나머지 전체가 평면도.
- **로비**: 상단 좌측 나가기, 중앙 4슬롯 가로 배치, 우하단 주 버튼.
- **캐릭터 선택 팝업**: 좌측 인디케이터 레일 → 중앙 프리뷰(450 폭) → 우측 정보 컬럼(700 폭) 3단.
- 모든 본부 조작 뷰와 미니게임, 아이템 상세는 **팝업(오버레이)** 로 구성.

| 화면 | 입력 | 결과 |
|---|---|---|

| 캐릭터 선택 | Select | 버튼 회색 + 이름표 빨간 윤곽선 + 체크, 로비 슬롯에 고양이 반영 |

| HUD | 우클릭 길게 | 마우스 위치에 원형 게이지 시계방향 충전 → 완료 시 사용 + 슬롯 비움 |
| HUD | T / M | 무전 발신(아이콘 초록 충전) / 무전기 비활성(빨강 + 취소선) |

| 본부 | 변수 발생 | 전체 경고 팝업 + 평면도 갱신 중단 + 탭 적색·비활성, X로만 해제 |
| 미니게임 | Esc | 세션 취소 |

## 5. 미확정 · 논의 중

- 화면별 UI 크기 기획서(HUD·본부·미니게임) 작성 중 — 위 3.1 외 수치 없음.
- 색상 HEX·폰트·행간 등 실제 디자인 토큰 전무. 2D 아트 시안 확정 후 이 문서 갱신 필요.
- 스프링클러 아이콘 크기 확대 여부(어몽어스 문 닫기 아이콘 스타일 검토 중).
- 타 플레이어 상태 표기: 체력바 안이 다수결로 채택됐으나 디자인적 표현 방식은 열려 있음.
- 작업 큐 3칸 UI 도입 여부.
- 층 셀렉터의 UI 형태(버튼 or 키).
- 본부 지도 표기 아이콘 세트(격벽 적·청, 스프링클러, 전등, 아군·적 마커, 미해금 해칭) 디자인 착수 전.
- 접근 불가·경고 팝업, 결과 화면, 암시장 화면, 무게 표시 UI 디자인 착수 전.
