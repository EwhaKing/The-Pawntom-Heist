# 튜토리얼 대본 (현재 버전)

> 코드의 `TutorialScriptLibrary.cs`와 `Tutorial_Scene.unity`에서 그대로 옮긴 **현재 대본**입니다.
> 이 문서를 수정해서 전달해 주시면, 그 내용을 기준으로 대본 코드와 맵을 고치겠습니다.
> 작성일: 2026-11-01 · 대사 원문은 코드와 한 글자도 바꾸지 않았습니다.

## 0. 이 문서 보는 법

| 항목 | 설명 |
|---|---|
| **구간 순서** | 대사 번호. `단계-번호` 형식입니다(예: 2-7). 진행 순서대로 재생됩니다. |
| **발동 위치** | 이 대사가 **언제·어디서** 나오는지. 맵 위의 장소 이름이나 플레이어 행동으로 적었습니다. |
| **캐릭터** | **지휘부**(무전으로 들리는 목소리) 또는 **깜냥이**(플레이어). |
| **대사** | 화면에 나오는 대사 원문입니다. |
| **비고** | 대사와 함께 뜨는 **키 안내 문구**, 대사 끝에 일어나는 **연출**, 재생 조건 등. 선택 항목이라 비워 두셔도 됩니다. |

- 같은 발동 위치에서 여러 줄이 이어지는 경우, 첫 줄에만 위치를 적고 나머지는 `〃`로 표시했습니다.
- **본 흐름**(순서대로 진행)과 **곁가지**(특정 상황에서 끼어드는 대사)를 구분해서 적었습니다. 곁가지는 제목에 `[곁가지]`가 붙어 있습니다.
- 키 안내의 `[ ]`는 화면에서 키 모양으로 강조됩니다. `{Interact}`는 상호작용 키(현재 **E**), `{TerminalExit}`는 단말기 나가기 키(현재 **Esc**)로 바뀝니다.

## 12. 수정하실 때 참고해 주세요

- **대사는 한 번에 한 줄씩** 나오고, 플레이어가 Space·클릭으로 넘깁니다(본 흐름 대사). 곁가지 대사는 플레이 중간에 끼어들므로 저절로 넘어갑니다.
- 한 번에 나오는 대사 묶음(예: 2-3~2-6)은 **트리거 하나**에 줄줄이 이어지는 구조입니다. 묶음 중간에 플레이어 행동을 기다려야 하면 묶음을 나눠 주세요.
- 새로 추가하려는 **열쇠 안내, 금고 해킹 후 연출** 같은 대사는 "발동 위치"만 명확하면 됩니다. 어떤 행동 뒤에 나오는지 적어 주세요.
- 화자는 **지휘부**와 **깜냥이** 두 명입니다. 다른 화자가 필요하면 알려 주세요(표시 이름·색·무전 효과를 새로 정해야 합니다).
- 지우거나 순서를 바꿀 대사는 그냥 지우거나 옮기셔도 됩니다. 번호(`2-7` 등)는 새로 매겨도 괜찮습니다.
