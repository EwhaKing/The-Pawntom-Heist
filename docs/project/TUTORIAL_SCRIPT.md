# 튜토리얼 대본 (최종 수정본)

## 0. 이 문서 보는 법

| 항목 | 설명 |
| --- | --- |
| **구간 순서** | 대사 번호. `단계-번호` 형식이며 진행 순서대로 재생됩니다. |
| **발동 위치** | 이 대사가 **언제·어디서** 나오는지. |
| **캐릭터** | **지휘부**(무전으로 들리는 목소리, 정체불명의 선대 괴도) 또는 **깜냥이**(첫 실전에 투입된 아기 고양이). |
| **대사** | 화면에 나오는 대사 원문. |
| **비고** | 키 안내 문구, 대사 끝 연출, 재생 조건 등. |

- 같은 발동 위치에서 여러 줄이 이어지면 첫 줄에만 위치를 적고 나머지는 `〃`로 표시합니다.
- `[곁가지]`는 특정 상황에서 끼어드는 대사입니다. `[택1]`은 같은 상황에서 조건에 맞는 한 줄만 나옵니다.
- 키 안내의 `[ ]`는 화면에서 키 모양으로 강조됩니다. 이 문서의 `[E]`, `[Esc]`는 현재 키 이름이며, 코드에 옮길 때는 키 바인딩을 따라가도록 처리합니다.

## 10. 코드 쪽에서 필요한 작업 메모

문서만 수정한 상태이며, 아래는 코드에 옮길 때 필요한 일입니다.

- **4단계 미니게임 랜덤**: 지금 코드는 4단계를 방향키 순서 입력으로 고정합니다. 랜덤으로 풀고, 어떤 종류가 걸렸는지 알리는 신호를 추가해야 4-8~4-10 `[택1]`을 나눌 수 있습니다. 금고는 Space 타이밍 고정을 유지합니다.
- **CCTV 안내 삭제(4-4~4-5)**: 4-4의 키 안내와 `CctvChecked`(CCTV 탭을 2.5초 본 뒤) 대기가 필요 없어졌습니다. 4-4와 4-5는 단말기 접속(`TerminalOpened`) 하나로 이어서 재생하면 됩니다.
- **디버프 아이콘 안내 삭제**: 코드 `TutorialScriptLibrary.cs`의 기존 7-6에 붙은 `[디버프 아이콘]을 확인합시다`(5초) 안내는 해당 UI가 없으므로 코드에 옮길 때 넣지 않습니다. 이 문서에는 처음부터 없습니다.
- **사망 재시도**: 튜토리얼은 사망하면 해당 구간 시작 전으로 되돌아가므로, 금고를 열기 전 상태로 복귀합니다. 열쇠·캣닢 분실 안내는 필요 없습니다.
- **캣닢 줍기(7-6~7-8)**: 금고 성공 직후 "캣닢이 주울 수 있는 상태" 신호가 필요합니다. 7-7(가방 가득 곁가지)은 기존 `InventoryFullRejected` 신호를 7단계 구간에 새로 열면 됩니다.
- **미니게임 문구**: 두 키 번갈아 누르기(4-9)의 키는 매번 무작위(WASD 중 2개)이므로, 키 안내는 화면에 표시된 키를 가리키는 형태입니다. 제한 시간은 게임별 기본 5초입니다.
- **R-gate-1·2**: 해킹 성공 후 단말기가 열려 있고 격벽이 아직 안 열린 상태를 감지하는 조건이 새로 필요합니다(기존 `IdleAtTerminal`을 구간만 바꿔 재사용 가능).
- **격벽 여닫기**: 격벽은 본부 단말기에서만 열고 닫습니다. 문 앞 [E] 상호작용은 없으므로, 5-1의 기존 `[E]키로 격벽을 열어봅시다` 안내는 삭제해야 합니다. 4-12의 안내는 "격벽이 열림" 신호(`DoorOpened`)로 해제하면 됩니다. 5-1b는 문 앞 도착 시 닫혀 있는 상태를 감지하는 조건이 새로 필요합니다.
- **열쇠**: 열쇠 근처 도착·획득을 알리는 신호가 필요합니다(5-7~5-9). 전리품 방 중앙의 열쇠 스폰과 금고의 열쇠 잠금 설정도 씬에서 확인해야 합니다.
- **무게 감속**: 5-3~5-4가 사실이 되려면 소지품에 따른 이동 속도 감소가 구현돼 있어야 합니다.
- **5-5 발동 조건**: 코드의 "가방 3칸 참" 신호를 그대로 씁니다.
- **8-7**: "메인 화면 이동"은 현재 연결돼 있지 않습니다(엔딩 완료 이벤트만 발생).
- 대사 번호가 1·3·4·5·6·7단계에서 바뀌었으므로 `TutorialScriptLibraryTests.cs`의 번호 목록도 함께 고쳐야 합니다.
