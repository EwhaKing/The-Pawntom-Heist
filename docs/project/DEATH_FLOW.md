# 사망 처리: 구현과 직접 확인할 항목

기획서 5.1 기준. 실제 쓰러짐 애니메이션은 제외하고 연결 지점만 제공한다.

## 현재 흐름

1. 호스트의 `PlayerData.ApplyDamage()`에서 HP가 0이 되면 영구 사망으로 확정하고 사망 좌표를 저장한다.
2. 이동·시점·점프·인벤토리·월드 상호작용을 막는다. 본인 해킹/본부/상점 창을 닫고, 적 감지 대상과 평면도 팀원 마커에서 제외한다.
3. 각 클라이언트에서 사망 연출 이벤트를 한 번 호출한다. 본인 카메라와 HUD에만 기존 흑백 효과를 적용한다.
4. 호스트의 애니메이션 종료 이벤트 또는 기본 1.5초 타임아웃 뒤 인벤토리를 드롭한다. `ItemData.modelPrefab`의 `NetworkObject`/`NetworkItem`을 사용하며 캣닢·열쇠도 포함한다. 성공한 슬롯만 비우고 실패한 슬롯은 1초 후 재시도한다.
5. 드롭 완료 상태를 복제하고, 각 클라이언트가 사망 위치에 기본 발자국·피격 흔적과 짧은 확산 효과를 표시한다. 자신의 흔적은 본인이 보는 사망/관전 카메라에서만 숨기고, 다른 플레이어와 다른 카메라에는 표시한다.
6. 로컬 사망 시 본인 카메라가 0.65초 동안 가속하며 바닥 위 0.25m로 내려가고 옆으로 78도 기운다. 바닥에 닿으면 0.24초 동안 작은 수직 반동과 감쇠 회전으로 충격을 표현하고, 0.35초 유지한 뒤 생존 팀원의 관전으로 전환한다. 관전 진입은 드롭 성공과 독립적이다. 좌/우 방향키로 전환하며, 대상이 죽거나 사라지면 자동으로 다른 생존자를 고른다. 생존자가 없으면 쓰러진 자신의 시점과 안내를 표시한다. 카메라 연출은 비배율 시간과 월드 좌표를 사용하며, 비활성화/디스폰 시 원래 로컬 위치와 회전을 복원한다.

기본 `player.prefab`와 적 테스트용 `player_Test.prefab`에 연출/관전 컴포넌트와 흔적 머티리얼을 연결했다. 카메라와 AudioListener 전환은 관전자 클라이언트에만 적용하며 입력 권한은 바꾸지 않는다. 흑백과 HUD도 현재 관전 카메라로 다시 연결한다. 원격 시점의 상하 회전은 `PlayerController.ViewPitch`로 복제한다.

## 애니메이션을 나중에 연결할 때

- 플레이어의 `PlayerDeathPresentation > On Death Presentation` 이벤트에 쓰러짐 Animator 트리거를 연결한다. 이 이벤트는 각 클라이언트에서 한 번 실행된다.
- Animator가 달린 오브젝트에 `PlayerDeathAnimationRelay`를 붙인다. 쓰러짐 클립 마지막 프레임의 Animation Event에서 `NotifyDeathAnimationFinished()`를 호출한다. 호스트만 이 이벤트로 드롭 시점을 확정한다.
- `PlayerData > Death Animation Timeout`은 클립 길이보다 여유 있게 설정한다. 이벤트가 없거나 누락돼도 이 시간이 지나면 진행한다. 현재 기본값은 1.5초다.
- 추가 VFX가 준비되면 `PlayerDeathPresentation > Death Effect Prefab`에 연결한다. 기본 발자국과 피격 흔적은 연결 없이 표시된다.

## Unity에서 확인할 체크리스트

Host와 Client를 각각 실행해 확인한다. 컴파일 확인만 수행했으며 아래 플레이 검증은 아직 실행하지 않았다.

- [ ] 적에게 피해를 받아 HP 0이 되면 이동/시점/점프/아이템 사용/획득이 멈추고 사망 상태가 유지된다. 추가 피해나 회복으로 사망 절차가 반복되거나 부활하지 않는다.
- [ ] 죽은 본인의 화면과 HUD만 흑백이 된다. 생존자의 화면과 CCTV 화면 색상은 그대로다.
- [ ] 애니메이션 연결이 없어도 약 1.5초 뒤 다음 절차로 넘어간다.
- [ ] 서로 다른 아이템과 같은 아이템 여러 개로 4칸을 채운 뒤 죽으면 슬롯별로 한 개씩, 총 네 개가 바닥에 드롭된다. 빈 인벤토리로 죽어도 관전으로 넘어간다.
- [ ] 캣닢을 포함한 모든 드롭이 양쪽 화면에서 같은 위치에 보인다. 과하게 크거나 바닥 안에 묻히지 않는다.
- [ ] Host와 Client가 각각 드롭을 주울 수 있다. 동시에 같은 아이템을 주우면 한 사람만 획득한다. 가방이 꽉 찼으면 월드 아이템이 남는다.
- [ ] 사망 위치에 발자국과 피격 흔적이 남고, 평면도에서 죽은 팀원 점이 사라진다. 적이 시체를 계속 추격하지 않는다.
- [ ] 사망 후 생존 팀원의 이동과 상하 시점이 관전 화면에 반영된다. 좌/우 방향키로 팀원을 바꿀 수 있고 살아 있는 팀원 조작에는 영향이 없다.
- [ ] Host와 Client가 각각 죽을 때 본인 화면이 가속하며 내려가고 옆으로 기운 뒤, 바닥 충격과 짧은 반동을 거쳐 약 1.24초 후 관전으로 넘어간다. 생존자 화면의 카메라는 움직이지 않는다. 생존자가 없으면 쓰러진 시점을 유지한다.
- [ ] 관전 대상이 사망하거나 방을 나가면 다른 생존 팀원으로 전환된다. 생존자가 없으면 안내가 나오고 오류가 발생하지 않는다.
- [ ] 해킹/본부 UI를 열어둔 채 사망해도 창이 닫히고 해킹 성공 보상이 발생하지 않는다. 죽은 뒤 다시 해킹/본부/상점을 열 수 없다.
- [ ] 맵을 나갔다가 새 게임에 들어오면 흑백/관전 UI/카메라 위치/숨겨진 캐릭터 렌더러 상태가 남지 않는다.

## 범위

게임 종료/전원 사망 결과창·로비 복귀·스테이지 초기화와 캣닢의 마킹/무전 차단/무게 디버프는 기획서 5.2의 별도 시스템이다. 이번 변경은 5.1의 사망 드롭 및 새 소지자가 인벤토리에서 동일한 캣닢 ID를 받는 경로까지 구현한다.

검증: 현재 프로젝트의 Unity C# 컴파일 응답 파일과 컴파일러로 빌드 성공. 기존 `DemoQuickStart.cs`의 CS4014 경고 한 건이 남아 있다. Unity 직접 연결 및 플레이 검증은 수행하지 않았다.
